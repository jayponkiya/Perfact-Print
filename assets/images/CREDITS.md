## Notes

- `services/banner-printing.jpg` shows a banner mid-print with a partial, mirrored event title on it. It is not a company brand, but swap it if you would rather have no text at all.
- `services/rubber-stamp.jpg` is cropped from the original to remove the law book's publisher name and website (top-left of the left page). Cropping is allowed under the Unsplash License.
- Small, blurred text that is not readable at display size remains on the screen-printing machine labels (`tshirt-screen-printing.jpg`) and a garment tag (`tshirt-heat-press.jpg`). Swap these if you want zero text.
- To replace an image: drop the new file in, then update its path and alt text in `js/images.js` and its row here.
